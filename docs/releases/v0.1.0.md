# JewelMentor v0.1.0

首个可复现的珠宝销售培训多 Agent 工程展示版本。

## Highlights

- Supervisor / Recommendation / Dialogue 三层协作与强类型 Handoff v1。
- SQLite 持久化状态机、检查点恢复、有限重试、deadline/hop 预算和幂等提交。
- 三份原创角色 Skill、短期上下文与训练记忆、知识依据和执行轨迹。
- 无密钥离线演示与 OpenAI-compatible 实时生成适配。
- 中文响应式训练工作台，支持专家切换、刷新加载与数据清除。
- 44 项自动化测试、30 条路由开发样本与 10 个正常/故障编排场景。
- 详细中文 README、英文概览、架构/恢复/评测/运维文档、Docker 与协作维护配置。

## Start

```bash
python -m venv .venv
# Activate the environment for your shell.
python -m pip install -e '.[dev]'
jewelmentor serve
```

Open http://127.0.0.1:8000. Default mode requires no API key.

## Scope

这是基于业务场景重建的个人作品，适合本地单进程体验。尚无登录/租户权限、分布式锁和数据库迁移。离线模板与结构代理分不代表真实模型质量或用户学习效果；没有在本次交付中消耗真实模型密钥。简历中的历史业务指标不作为本仓库实测指标。
